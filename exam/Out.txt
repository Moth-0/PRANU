The comparison of the adaptive 2 split method from homework 
and the new adaptive 3 split integrator. 
We can see that the 3 split fails and the 2 split uses a lot of calls 
for the function 1/sqrt(x) since it can not evaluate 1/sqrt(0). 
------------------------------------------------------------------------------------------
Function            Method         Result         Error          Est. Error     Evals     
------------------------------------------------------------------------------------------
sqrt(x)             2-Split        0.666681       -1.42662e-05   7.17421e-05    40        
                    3-Split        0.666677       -1.04652e-05   6.3409e-05     33        

1/sqrt(x)           2-Split        2              2.61204e-06    7.70898e-05    17140     
                    3-Split        inf            -inf           nan            12219     
------------------------------------------------------------------------------------------

To fix this we use Clenshaw Curtis to rewtrite the function, 
this allows the function value to be finite: 
------------------------------------------------------------------------------------------
Function            Method         Result         Error          Est. Error     Evals     
------------------------------------------------------------------------------------------
sqrt(x)             CC-2-Split     0.666667       1.13668e-07    7.98719e-05    64        
                    CC-3-Split     0.666666       2.66896e-07    5.38161e-05    63        

1/sqrt(x)           CC-2-Split     2              1.09689e-07    6.90012e-05    52        
                    CC-3-Split     2              2.50819e-07    0.000104398    27        
------------------------------------------------------------------------------------------
